## 📜 Welcome, Software Knights!

The peaceful **Kingdom of Codoria** has been attacked by the mysterious **Dark Bug**. Its code has been corrupted, its routes have disappeared, and its valuable data is in danger.

The kingdom has summoned a new generation of **Software Knights**. Your task is to work with your team, complete coding missions, defeat bugs, collect Kingdom Points, and restore Codoria one system at a time.

Each repository in this organization contains a different mission. Open the mission repository and read its `README.md` to receive your instructions.

> Every bug defeated brings the kingdom one step closer to peace. 🐛⚔️

## 🧙 The Guardians of the MEN Stack

Three powerful guardians protect the kingdom's backend:

### 🍃 MongoDB — Keeper of the Royal Records

Stores and protects the kingdom's data, citizens, quests, and ancient records.

### 🗺️ Express — Guardian of the Kingdom's Routes

Controls the paths through the kingdom and makes sure every request reaches the correct destination.

### ⚔️ Node.js — Power of the Royal Server

Brings JavaScript to the server and supplies the power needed to run the kingdom's systems.

## 👥 The Royal Teams

The class will be divided into **9 teams of 3 Software Knights**. Each knight has an important role:

| Role | Responsibility |
|---|---|
| ⚔️ **Knight Coder** | Controls the keyboard and writes the code |
| 🧭 **Royal Navigator** | Reads the mission and guides the team |
| 🔍 **Bug Hunter** | Tests the code and investigates errors |

Roles must rotate during future missions so that every knight gets an opportunity to code, guide, and debug.

---

## 🚨 How Missions Work

When a mission is unlocked:

1. Enter the mission repository.
2. Read the mission briefing in its `README.md`.
3. Assign the three team roles.
4. Start the mission when the instructor begins the timer.
5. Repair, build, or investigate the code.
6. Test the result before declaring victory.
7. Choose one knight to explain the team's solution.
8. Collect Kingdom Points!

Most missions are short challenges designed to take approximately **8–15 minutes**.

## 🏆 Kingdom Points

Teams collect points throughout their journey. The exact score may change depending on the mission, but most missions use the following system:

| Achievement | Points |
|---|---:|
| Complete the main mission | 8 |
| Explain the solution clearly | 4 |
| Every knight participates | 3 |
| Complete the bonus quest | 3 |
| Use clear code and a meaningful commit | 2 |
| **Maximum points per mission** | **20** |

### 👑 Royal Ranks

| Total team points | Rank |
|---:|---|
| 0–39 | 🪶 Royal Recruit |
| 40–79 | 🛡️ Code Squire |
| 80–119 | ⚔️ Software Knight |
| 120–159 | 🏹 Senior Bug Hunter |
| 160+ | 👑 Guardian of Codoria |

Points reward teamwork, understanding, and clear explanations—not only speed.

## 📖 The Royal Code

Every Software Knight must follow these rules:

- 🤝 Work with your assigned team.
- 🗣️ Make sure every team member participates.
- 🧠 Understand the code your team submits.
- 🧪 Test the code before declaring the mission complete.
- 💬 Ask for help when your team is truly stuck.
- 🚫 Do not copy another team's solution.
- 🤖 Do not submit AI-generated code that your team cannot explain.
- ✍️ Use meaningful variable names, readable formatting, and clear commits.
- ❤️ Respect and support your fellow Software Knights.

## 🔮 Hints and Assistance

Some mission repositories contain hidden hints. A team may open a hint if needed, but the mission README will explain whether using it affects the team's points.

Getting stuck is not failure. Investigating errors, reading messages, testing ideas, and asking good questions are all part of becoming a software engineer.
